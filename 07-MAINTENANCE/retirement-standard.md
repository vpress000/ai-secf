# Configuration Retirement Standard

Retire an artifact when its workflow no longer exists, it is superseded, unsupported, unsafe, or redundant.

Before removal:
- identify consumers and references;
- determine whether the file is user-authored or generated;
- record why it is obsolete;
- check for dependencies from other config files;
- obtain approval for consequential removals;
- remove references and update the manifest;
- run validation and retain a change record.

Do not leave misleading empty stubs or stale instructions.
