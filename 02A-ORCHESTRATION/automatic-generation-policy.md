# Automatic Generation and Approval Policy

## Safe to generate automatically after discovery
Subject to evidence and preservation rules:
- project profile and discovery notes;
- configuration blueprint and manifest;
- concise root `CLAUDE.md`;
- ordinary documentation and rule files;
- narrowly scoped agent or skill definitions when clearly justified and non-executable;
- validation and maintenance reports.

## Generate only when justified
- nested instruction files;
- custom agents, skills, commands;
- shared project settings that do not broaden permissions;
- reference maps and workflow guides.

## Draft and require approval before activation
- permission grants or permission-mode changes;
- hooks and executable automation;
- MCP servers and external integrations;
- plugins, marketplaces, external services;
- commands with destructive or external side effects;
- credentials, secrets, network access, or data-sharing behavior.

## Do not generate
- fabricated project facts or fake commands;
- placeholder credentials;
- broad permission grants as convenience defaults;
- empty files/directories to imitate a sample structure;
- duplicate mechanisms for the same workflow without a reason;
- personal user-level configuration unless explicitly requested.
