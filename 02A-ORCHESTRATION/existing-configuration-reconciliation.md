# Existing Configuration Reconciliation

## Inventory each artifact
Record:
- path and native artifact type;
- ownership: user-authored, team-authored, generated by AI-SECF, generated by another tool, unknown;
- purpose and scope;
- whether Claude Code currently recognizes it;
- quality, freshness, and references;
- duplication or conflict relationships;
- proposed disposition.

## Disposition categories
- **Keep:** Valid, useful, compatible, and consistent.
- **Reuse:** Retain content and reference it from other instructions.
- **Update:** Correct stale, incomplete, conflicting, or noncompliant content.
- **Create:** Add a missing artifact justified by project needs.
- **Consolidate:** Merge duplicated content while preserving meaning and scope.
- **Deprecate:** Mark obsolete and propose a migration.
- **Remove:** Only when clearly safe, authorized, and no longer referenced.

## Reconciliation rules
- Never assume an existing file is disposable because it differs from a template.
- Preserve comments, custom sections, and local conventions unless they are demonstrably unsafe or invalid.
- Do not overwrite files with unknown ownership.
- Make minimal diffs.
- Maintain references and cross-file dependencies.
- If two sources conflict, report the conflict and resolve according to verified Claude Code precedence and project-owner intent; do not guess.
- Never copy local secrets or personal settings into shared configuration.
