# Changelog

## 1.0.0
- Reframed the package as a dedicated framework for AI coding-assistant configuration.
- Established discovery, configuration design, generation, validation, security, and maintenance lifecycle.
- Added Claude Code artifact standards for CLAUDE.md, rules, settings, agents, skills, commands, hooks, and MCP.
- Added project bootstrap workflow, templates, manifest, validation checklist, and maintenance guidance.
- Explicitly excluded general software engineering governance from framework scope.

## 1.1.0
- Clarified AI-SECF as an executable configuration-generation and reconciliation workflow.
- Added explicit new-project and existing-project operating modes.
- Added idempotent reconciliation, artifact dependency mapping, and ecosystem coherence checks.
- Defined automatic generation boundaries versus approval-gated runtime changes.
- Strengthened completion criteria around preservation, reuse, and minimal necessary changes.
