# Skills Standard

Use skills for reusable, task-oriented capabilities that Claude should load when relevant.

A skill should:
- follow the current documented directory and `SKILL.md` format;
- use valid frontmatter and concise descriptive metadata;
- explain its trigger/use case and expected result;
- provide a repeatable workflow, not generic project policy;
- reference supporting files only when necessary;
- keep supporting material focused and discoverable;
- avoid embedding secrets or unsafe executable actions;
- state where human confirmation is required.

Prefer one well-designed skill over several overlapping skills. Verify the current platform behavior for automatic discovery and invocation.
