# Agent Definition Standard

Create a subagent only for a bounded role with a distinct context, tool needs, or delegation benefit.

Every agent definition must:
- use current documented file placement and frontmatter;
- have a precise name and single responsibility;
- define when it should and should not be used;
- state expected inputs and outputs;
- limit tools to those required;
- avoid claiming authority to approve consequential changes;
- avoid duplicating the primary assistant's general instructions;
- define escalation conditions for ambiguity or risk.

Do not create agents solely to simulate organizational titles or inflate the configuration.
