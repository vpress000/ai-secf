# AI-SECF Configuration Maintenance Prompt

Review this repository's Claude Code configuration using the AI-SECF framework.

1. Read the current configuration manifest and validation report.
2. Inspect repository changes since the last configuration review.
3. Identify stale paths, commands, technology references, rules, agents, skills, hooks, settings, and integrations.
4. Check current Claude Code documentation for compatibility changes.
5. Identify duplication, conflicts, excessive context, and unused artifacts.
6. Propose a minimal change plan with evidence and risk.
7. Do not overwrite user-authored content or change permissions, hooks, MCP, plugins, or external integrations without explicit approval.
8. After approval, apply changes incrementally and validate.
9. Update the manifest, validation report, and change record.
10. Report items that need human decisions.
