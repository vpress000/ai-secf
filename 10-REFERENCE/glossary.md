# Glossary

- **AI-SECF:** AI Software Engineering Configuration Framework.
- **Artifact:** A file or configuration component generated or governed by the framework.
- **Project profile:** Evidence-backed description of a repository relevant to Claude configuration.
- **Configuration blueprint:** Proposed artifact set, scopes, rationale, dependencies, and approvals.
- **Root instructions:** The repository's top-level `CLAUDE.md`.
- **Scoped instructions:** Guidance applying only to particular directories, file patterns, or tasks.
- **Skill:** A reusable, task-oriented capability using Claude Code's documented skill mechanism.
- **Subagent:** A specialized delegated Claude agent defined through the supported mechanism.
- **Hook:** Event-triggered automation in Claude Code.
- **MCP:** Model Context Protocol integration for external tools or data.
- **Shared project settings:** Version-controlled settings intended to apply to collaborators.
- **Local settings:** Personal, machine-specific project settings; not a shared project artifact.
- **Configuration drift:** Mismatch between configuration and the current repository, workflow, or platform.
- **Minimum sufficient configuration:** The smallest artifact set that adequately supports the project's Claude workflows.
