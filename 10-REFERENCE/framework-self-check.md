# Framework Self-Check

Before releasing an AI-SECF version, verify:

- [ ] Scope is explicitly limited to AI assistant configuration.
- [ ] No general SDLC or application engineering policy has crept into scope.
- [ ] Claude Code native capabilities are accurately represented.
- [ ] Every artifact standard distinguishes universal design guidance from platform syntax.
- [ ] Optional capabilities are conditional, not mandatory.
- [ ] Security and approval boundaries are explicit.
- [ ] Templates are internally consistent.
- [ ] Bootstrap workflow can be followed without hidden assumptions.
- [ ] Validation checks can be performed and reported honestly.
- [ ] Version and migration guidance are present.
